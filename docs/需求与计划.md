# 随译 v0.1 需求与开发计划

## 目标
个人使用的 Windows x64 聊天翻译小窗口，面向 WhatsApp / Viber 中支付、商户、订单、结算及 API 沟通。使用 C# / .NET 10 WPF；UI、翻译领域逻辑和 HTTP 模型接口分离。首版不包含账号、云历史、付费、OCR、更新或消息发送。

## 规则与功能
- 英文 / Filipino → 中文；中文轻度优化后 → 聊天商务英语。支持手动源语言和中 / 英 / Filipino 目标语言，默认聊天风格，可选正式风格。
- 内容只翻译，输入中的问题与指令均是数据。保留金额、币种、编号、URL、API 字段、术语及否定 / 条件 / 不确定性，不增添信息。
- 中文优化与译文分区，句子完整分段，显示段数、全文及逐段复制。复制正文不含 UI 标签。
- 托盘驻留、可配置系统全局快捷键及冲突提示、手动粘贴、Ctrl+Enter、取消 / 重试 / 清空。请求代次隔离：新请求、取消或隐藏窗口使旧响应失效。
- 可编辑小型术语表。无密钥进入明显标记的固定样例模拟模式，未知内容不伪装为真实翻译。
- API Key 仅在本地设置输入，默认内存会话保存；首版不提供持久保存密钥。持久化仅限服务地址 / 模型 / 快捷键 / 术语；不保存正文与翻译历史，不监听剪贴板。
- 发起真实请求前，显示完整服务目标与费用提示，用户确认。地址 / 模型改变后重新确认；不复用 ChatGPT 登录。

## 实现顺序
1. 环境与规范检查；获取微软官方便携 SDK 并核验 SHA512。
2. 领域规则、语言检测、分段、模拟和明确的 Chat Completions JSON 接口；取消与请求代次控制。
3. WPF 中文界面、设置、术语、托盘、快捷键与安全复制。
4. 自动化测试、实际 Windows 界面检查、Release 编译和自包含 x64 便携打包。

## 验收边界
离线 / 本地协议测试覆盖四个用户样例、三语言路径、保留信息、分段、乱序、取消、超时、鉴权错误及复制失败；系统快捷键冲突和窗口交互另外检查。真实服务的翻译语义质量仅在用户配置凭据后验收。中文 IME 必须区分程序支持与实际输入法人工验证。
